# Guia de Identidade Visual — Maíra Cazzuni

## Nova direção visual principal

Referência principal do hero:
public/references/hero-premium-reference.png

A landing page deve seguir essa direção estética.

Características principais:
- vinho profundo sofisticado
- dourado premium como segunda cor protagonista
- atmosfera luxury editorial
- composição elegante
- hero cinematográfico
- aparência high-end
- contraste refinado entre vinho e dourado
- tipografia sofisticada
- visual forte e premium

O hero deve transmitir:
- autoridade
- sofisticação
- exclusividade
- confiança
- luxo silencioso

Importante:
o dourado deve fazer parte ativa da composição visual da página, principalmente:
- botões
- detalhes
- títulos estratégicos
- divisórias
- ícones
- microelementos premium
- elementos de destaque

Evitar:
- aparência genérica
- excesso de vermelho vivo
- visual pesado
- visual de template jurídico comum

## Cores principais

### Vinho profundo

HEX: #4A0001

Uso:
- botões principais
- detalhes de destaque
- blocos de autoridade
- títulos estratégicos
- elementos de marca

Sensação:
- força
- poder
- autoridade
- sofisticação
- presença

### Branco

HEX: #FFFFFF

Uso:
- fundo principal
- áreas de respiro
- contraste com o vinho

Sensação:
- limpeza
- clareza
- elegância
- confiança

### Dourado elegante

HEX: #D1AF66

Uso:
- botões principais
- botões secundários
- CTAs estratégicos
- detalhes de destaque
- linhas elegantes
- ícones
- estrelas de avaliação
- hover de elementos
- bordas sofisticadas
- microdetalhes premium
- elementos de composição visual
- destaques importantes da interface

O dourado deve funcionar como a segunda principal cor da identidade visual, ajudando a criar contraste sofisticado com o vinho profundo.

Importante:
usar com elegância e equilíbrio.

O dourado deve transmitir:
- sofisticação
- exclusividade
- luxo silencioso
- autoridade premium

Evitar:
- aparência exagerada
- excesso de brilho
- visual cafona
- sensação de “luxo fake”

### Preto/chumbo

HEX: #1C1917

Uso:
- textos principais
- títulos
- subtítulos
- textos de leitura

Sensação:
- sofisticação
- contraste
- seriedade
- estabilidade visual

## Estilo visual de referência

Referência principal:

https://site-gioia.vercel.app/

O projeto da Maíra deve se inspirar na sensação visual dessa referência:

- bastante espaço em branco
- layout limpo
- visual premium
- tipografia elegante
- hierarquia clara
- imagem profissional forte
- seções bem respiradas
- experiência mobile refinada

Não copiar a referência literalmente.  
Usar apenas como direção estética.

## Direção visual

A página deve ter:

- fundo claro dominante
- detalhes em vinho profundo
- detalhes discretos em dourado
- textos em preto/chumbo
- cards elegantes
- bordas suaves
- sombra discreta
- bastante espaçamento
- visual leve e premium

## Tipografia

Sugestão:

Títulos:
- Playfair Display
- Cormorant Garamond
- ou uma fonte serifada elegante

Textos:
- Inter
- ou uma fonte sem serifa limpa e moderna

Os títulos devem transmitir autoridade e sofisticação.  
Os textos devem ser fáceis de ler, principalmente no celular.

## O que evitar

Evitar:

- vermelho muito vivo
- dourado exagerado
- excesso de gradientes
- excesso de animações
- layout pesado
- visual escuro demais
- aparência de panfleto
- aparência de advogado genérico
- blocos muito grudados
- textos longos demais no mobile
