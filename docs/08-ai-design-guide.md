# AI DESIGN GUIDE — Maíra Cazzuni

A principal referência visual do projeto agora é:
public/references/hero-premium-reference.png

A direção visual da landing page deve seguir essa estética.

O hero deve parecer:
- cinematográfico
- premium
- editorial
- sofisticado
- elegante
- moderno
- high-end

A composição deve priorizar:
- contraste refinado entre vinho profundo e dourado
- tipografia elegante
- atmosfera luxuosa
- equilíbrio visual
- composição sofisticada entre texto e imagem

A foto da Maíra deve ser protagonista do hero.

O layout deve transmitir:
“advogada criminalista premium e altamente preparada.”

## Uso da imagem Lady Justice

A imagem:
public/brand/lady-justice-bg.jpg.jpg

deve ser utilizada em uma seção estratégica da landing page como elemento atmosférico premium.

Importante:
a imagem NÃO deve competir com a foto da Maíra no hero principal.

A Lady Justice deve funcionar como:
- composição cinematográfica
- textura visual sofisticada
- elemento de autoridade
- atmosfera premium

Melhores usos:
- CTA final
- fundo de seção estratégica
- separador visual entre seções

Aplicar:
- baixa opacidade
- overlay escuro elegante
- blend sofisticado
- possível blur suave
- integração refinada com o layout

Evitar:
- aparência clichê jurídica
- uso exagerado
- imagem muito evidente
- excesso de contraste
- composição pesada

## Objetivo visual

Criar uma landing page premium para advocacia criminal que transmita:

- autoridade
- sofisticação
- segurança
- elegância
- poder
- confiança
- acolhimento estratégico

A sensação visual deve ser de:
“advogada altamente preparada e confiável”.

# Estilo do Hero

O hero deve ser a seção mais impactante da página.

Precisa transmitir imediatamente:
- autoridade
- confiança
- sofisticação
- segurança

Estrutura recomendada:

## Lado esquerdo
- headline forte
- subtítulo curto
- CTA WhatsApp
- microcopy de sigilo

## Lado direito
- foto profissional da Maíra
- composição elegante
- iluminação premium

---

# Fundo do Hero

Usar fundo claro com detalhes sofisticados.

Pode utilizar:
- textura suave
- formas orgânicas discretas
- imagem da deusa da justiça muito sutil
- overlay elegante

Nunca usar fundo pesado ou poluído.

# Espaçamento

Usar MUITO espaço visual.

A página deve respirar.

Evitar:
- elementos apertados
- excesso de texto
- seções coladas
- cards pequenos demais

---

# Cards

Cards devem parecer premium.

Usar:
- bordas suaves
- sombra leve
- fundo branco
- bastante padding
- textos curtos
- ícones discretos

---

# Botões

Botão principal:
- vinho #6A150F
- texto branco
- elegante
- grande o suficiente para mobile

Hover:
- leve escurecimento
- detalhes sutis em dourado

---

# Mobile First

A experiência mobile é prioridade absoluta.

A página deve:
- carregar rápido
- ter leitura confortável
- ter CTA visível rapidamente
- evitar excesso de altura
- evitar textos longos
- manter aparência premium no celular
